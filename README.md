# birfree-arch

Instala o Birfree num Arch Linux minimal recém-instalado.

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/NEOpisa/birfree-arch/main/instalar-birfree-arch)
```

- `--conferir`: só baixa e confere a release e a data do Arch, sem alterar nada.
- `BIRFREE_DATA=AAAA/MM/DD`: outra data do Arch Linux Archive (padrão 2026/10/01).
- Também deixa o zsh com o powerlevel10k (configs/zsh) como shell padrão.
